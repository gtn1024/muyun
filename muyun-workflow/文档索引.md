## 🚀 快速开始（3分钟）

### 第一步：创建流程定义
```java
// 创建流程、节点、流转
String definitionId = workflowDefinitionController.create(Map.of(
    "v_name", "请假审批",
    "v_code", "leave_approval",
    "dict_workflow_status", "draft"
));
// ... 创建节点和流转 ...
// 激活流程
workflowDefinitionController.update(definitionId, Map.of(
    "dict_workflow_status", "active"
));
```

### 第二步：业务集成
```java
@Path("/leave_request")
public class LeaveRequestController extends ScaffoldForPlatform
    implements IWorkflowAbility {
    
    @Inject
    WorkflowEngine workflowEngine;
    
    @Override
    public String getWorkflowCode() {
        return "leave_approval";  // 对应上面创建的流程编码
    }
    
    @POST
    @Path("/submit/{id}")
    public String submit(@PathParam("id") String id) {
        return workflowEngine.startProcess(
            getWorkflowCode(), id, "leave_request",
            getUser().getId(), Map.of()
        );
    }
    
    @Override
    public void afterWorkflowApproved(String id) {
        this.update(id, Map.of("dict_status", "approved"));
    }
}
```

### 第三步：处理任务
```java
// 获取待办
PageResult<Map> todoList = workflowTaskController.getTodoList(1, 10);

// 完成任务
workflowEngine.completeTask(taskId, "同意", "同意此申请", Map.of());
```

| 类/接口 | 说明 | 位置 |

## ⚠️ 重要注意事项

1. 流程定义必须**激活**（`dict_workflow_status = 'active'`）才能使用
2. 每个流程只能有**一个开始节点**
3. 审批节点必须**指定办理人**
4. 流程编码（`v_code`）必须**唯一**
5. 业务表需要添加 `id_at_workflow_instance` 字段关联流程实例
